# Архитектурные и редакционные решения

## Global AI relevance gate

- **Решение:** AI relevance gate является обязательным глобальным этапом для автоматически отбираемых материалов.
- **Причина:** разделы могут иметь разные настройки и scoring, но не должны обходить общую AI-направленность REVELATIONS.

- **Решение:** gate выполняется до section-specific scoring.
- **Причина:** неподходящий материал не должен получать section score или становиться qualified candidate.

- **Решение:** случайного или фонового упоминания AI недостаточно.
- **Причина:** AI должен быть центральной и доминирующей темой материала.

- **Решение:** обычные Places-материалы без существенной AI-трансформации не подходят для автоматического отбора.
- **Причина:** эстетика, архитектура или общая технологичность места сами по себе не выполняют глобальную AI-политику.

## Безопасность автоматизации

- **Решение:** автоматические scanners пока остаются выключенными; не включать и не запускать автоматизацию без отдельного решения.
- **Причина:** семантика AI gate и технические проверки ещё не завершены.

- **Решение:** lint, static checks, synthetic tests и другие технические проверки не должны создавать кандидатов, черновики или публикации.
- **Причина:** верификация должна быть изолированной и не менять редакционные данные.
